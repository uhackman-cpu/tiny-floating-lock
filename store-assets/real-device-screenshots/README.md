# Real Device Screenshots for Play Store

Place the five genuine screenshots captured from the Tiny Floating Lock app on a physical Android device in this folder. Use the exact filenames below so they can be matched to the existing promotional mockups.

1. `01_Tiny_Floating_Lock_HD.png` — actual floating lock button visible over the phone's Home Screen.
2. `03_Double_Tap_Power_Menu_HD.png` — Android Power Menu opened by double-tapping the floating button.
3. `05_Long_Press_Quick_Controls_HD.png` — the real quick-controls panel after long-pressing the button.
4. `08_Appearance_Settings_HD.png` — the app's real appearance settings screen showing size/opacity controls.
5. `09_Accessibility_Setup_HD.png` — Android Accessibility Settings showing Tiny Floating Lock's actual service entry and toggle.

## Capture instructions

- Capture directly on the test phone; do not recreate, paint over, or mock the UI.
- Save as PNG, preferably the original full-resolution screenshot.
- Ensure the app name and relevant controls are readable; hide personal notifications if needed.
- Check the exact release build's behavior before capturing.
- If Android's Power Menu or Accessibility Settings looks different on your phone, keep the real device appearance. Do not edit it to resemble the mockup.
- Do not upload APKs, keystores, passwords, or unrelated personal screenshots here.

Once the files are uploaded, compare each screenshot with the app release and update the asset pack before Play Store submission.
